# ADR-0006 — executable Pass Two department handoffs
Status: ACCEPTED
Date: 2026-11-12

The previous animation jobs failed because role-wide aspirations were mistaken for blockers. The following APIs are approved now. Each department must implement its complete scoped contribution; integration and executable QA occur downstream without model credentials. No reference images are assumed. Source-generated pixel art and synthesized music are the chosen media for this pass.

## Character Animator — game/animation/operator.mjs
Export CLIPS, samplePose(action,time), animationEvents(action,from,to). Six action keys: idle, walk, climb, observe, valve, recoil. Each clip: {fps:18,loop:boolean,frames:[{bob,leg,arm,lean,events:[]}]}; offsets are finite pixels within [-8,8], at least 4 distinct frames per clip. Walking/climbing loop; recoil does not. samplePose returns a fresh frame at floor(time*18), clamping non-looping clips; unknown action falls back to idle. Time must be finite and nonnegative. animationEvents returns [{name,time}] for markers in (from,to], including loop boundaries, in chronological order; reject invalid/reversed ranges or ranges longer than 2 seconds. Markers are footstep, ladder.step, inspect.raise, valve.rotate, recoil. The world renderer consumes offsets directly in its existing PPE sprite; the audio scheduler consumes markers. No DOM, clocks, drawing, audio, simulation writes or external imports.

## Environment Animator — game/world/parallax.mjs
Export BIOMES, environmentAt(sceneId,time), drawParallax(ctx,sceneId,camera,time,options={}). Four IDs: hub, backyard, warehouse, heat-hold. BIOMES supplies at least three authored layers per scene with {kind,speedX,speedY,color,spacing}, plus weather and palette; scene definitions must differ. environmentAt returns {wind,airflowFactor,draftFactor,heatLossFactor,weather}; factors bounded [0.75,1.2], wind [-1,1], deterministic and visibly/weather-coherent. Hub factors are 1; Backyard crosswind varies smoothly; Warehouse restriction is persistent; Heat-Hold has greater heat loss. These factors multiply the job's original solver definition at each fixed simulation step, never accumulate. A safe manual tune must remain possible for all three jobs. Invalid IDs/time throw.

drawParallax uses screen-space camera {x,y,width,height}, integer pixel rectangles and ctx.save/restore. options.foreground false draws distant infrastructure/haze; true draws sparse weather. options.reducedMotion freezes weather motion. options.protectedAreas is an array of screen rectangles {x,y,w,h}; skip every foreground rectangle intersecting one. The consumer derives these from the player's rendered bounds, physical interaction props and overlay controls. Never modify scene/camera/protectedAreas, collisions, touch targets or simulation. No randomness, DOM, clock reads, audio, or external resources. Retain original industrial authored detail rather than a generic rectangle utility.

## Narrative Designer — game/narrative/story-flags.mjs
Export StoryState class. constructor(snapshot=null), snapshot(), record(event,jobId=null), dialogue(context). snapshot returns plain {version:1,flags:{metOperator:boolean,learnedDraft:boolean,backyardComplete:boolean,warehouseComplete:boolean,heatHoldComplete:boolean,assisted:boolean},choice:'independent'|'assisted'|null}. Validate/restored fields conservatively; unknown future version resets safely. record accepts meet, diagnose, assist, complete; complete requires one of the three job IDs; idempotent, no rewards. dialogue({jobId,mainLit,damperRepaired}) returns fresh {icon,text,options:[{id,icon,text}]} with 2-3 meaningful options from diagnose/assist/independent/leave. Narrative text is optional help; icons convey core state. Branch on actual mission, repair and completion flags, including an independent versus assisted path. No campaign finale or repeat reward in this pass, no DOM, storage or burner mutation.

## Composer — design/audio/original-themes.json
JSON {version:1,provenance:{creatorRole,method,source:'original',license:'CC0-1.0',date},themes:{hub,backyard,warehouse,'heat-hold'}}. Each theme: {bpm,stepsPerBar:16,bars:4,chords:[[midi,...],...],melody:[{step,midi,duration,velocity}]}. Four chord arrays (3-4 notes each), 12-32 original melody notes, step in [0,64), duration in [.25,8], velocity in (0,1], MIDI 36-90, BPM 72-174. Compose memorable industrial liquid-DnB/orchestral motifs with a calmer hub; no borrowed melodies or audio. This data is directly consumable by the arranger; a JSON theme is a score, not an audio recording.

## Orchestrator — assets/audio/original-score.json
After Composer acceptance, export JSON {version:1,provenance:{creatorRole,method,source:'original',license:'CC0-1.0',date},themes:{hub,backyard,warehouse,'heat-hold'}}. Each theme {bpm,stepsPerBar:16,bars:4,voices:[{id,waveform,gain,tensionMin,notes:[{step,midi,duration,velocity}]}]}. 3-5 voices: pad, bass, melody and optional pulse/percussion. waveform sine/triangle/square/sawtooth; gain [.005,.14]; tensionMin [0,1]. Notes follow Composer timing/ranges, bass MIDI >=24; max 96 notes/voice. Preserve composer motifs and chords. A trusted build script creates game/audio/score-data.mjs. The reusable Web Audio scheduler uses audio-clock lookahead, bounded voice count, user-gesture unlock and explicit mute/suspend; no external audio or invented mastered stems.

## AV Sync Director — game/audio/event-sync.mjs
Export EVENT_CUES and cueForEvent(name). Cues for footstep, ladder.step, inspect.raise, valve.rotate, recoil, pilot.spark.begin, pilot.ignite, main_flame.attach, combustion.puff, chamber.overheat, mission.stable, mission.fail, biome.wind_gust, repair.complete. Values: {waveform,frequency,endFrequency,duration,gain,offsetSeconds}. waveform one of the four oscillator types, frequencies [35,2600], duration [.025,.6], gain [.002,.12], offsetSeconds [0,.035]. Unknown event returns null; returned cue is a fresh object. Distinct semantic cues, restrained volume; physical event timestamps schedule directly on AudioContext.currentTime, never world/flame presentation frames. Source-only module, no DOM, clock reads, AudioContext creation or state writes.
